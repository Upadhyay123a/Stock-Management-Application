# MySQL Setup Guide

This guide will help you set up MySQL for the Stock Management Application.

## Installation

### Windows

1. Download MySQL from: https://dev.mysql.com/downloads/mysql/
2. Run the installer and follow the setup wizard
3. During installation:
   - Port: 3306 (default)
   - Root password: Set your preferred password
   - Configure MySQL as a Windows service

4. Verify installation:
```cmd
mysql --version
```

### macOS

Using Homebrew:
```bash
brew install mysql
brew services start mysql
```

### Linux (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install mysql-server
sudo mysql_secure_installation
```

## Database Setup

### 1. Connect to MySQL

```bash
mysql -u root -p
# Enter your root password when prompted
```

### 2. Create Databases

```sql
-- Create production database
CREATE DATABASE stock_management;

-- Create test database
CREATE DATABASE stock_management_test;

-- List databases to verify
SHOW DATABASES;
```

### 3. Create Tables (Auto-generated by Hibernateupdate)

The tables will be created automatically when you start the Spring Boot application due to:
```properties
spring.jpa.hibernate.ddl-auto=update
```

### 4. Verify Setup

```sql
-- Switch to the database
USE stock_management;

-- Check tables (after first run)
SHOW TABLES;

-- Check Stock table structure
DESCRIBE stock;
```

## Configuration in Application

### Main Application (Production)

File: `src/main/resources/application.properties`

```properties
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.url=jdbc:mysql://localhost:3306/stock_management
spring.datasource.username=root
spring.datasource.password=root
spring.jpa.hibernate.ddl-auto=update
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect
```

### Test Application

File: `src/test/resources/application.properties`

```properties
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.url=jdbc:mysql://localhost:3306/stock_management_test
spring.datasource.username=root
spring.datasource.password=root
spring.jpa.hibernate.ddl-auto=create-drop
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect
```

## Common MySQL Commands

### Connect to MySQL
```bash
mysql -u root -p
```

### Show all databases
```sql
SHOW DATABASES;
```

### Switch to a database
```sql
USE stock_management;
```

### View all tables
```sql
SHOW TABLES;
```

### View table structure
```sql
DESCRIBE stock;
```

### View all records in stock table
```sql
SELECT * FROM stock;
```

### Check MySQL server status
```bash
mysql -u root -p -e "STATUS;"
```

### Backup database
```bash
mysqldump -u root -p stock_management > backup.sql
```

### Restore database
```bash
mysql -u root -p stock_management < backup.sql
```

## Troubleshooting

### Connection Refused
- **Problem**: "Connection refused" when connecting
- **Solution**: Ensure MySQL server is running
  ```bash
  # Windows
  net start MySQL80  # or your MySQL service name
  
  # macOS
  brew services start mysql
  
  # Linux
  sudo systemctl start mysql
  ```

### Wrong Password
- **Problem**: Access denied for user 'root'
- **Solution**: Reset MySQL root password
  ```bash
  # Windows
  mysqld --skip-grant-tables
  
  # Then in another terminal
  mysql -u root
  FLUSH PRIVILEGES;
  ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_password';
  ```

### Port Already in Use
- **Problem**: Port 3306 is already in use
- **Solution**: Either stop the other service or configure MySQL to use a different port
  ```properties
  spring.datasource.url=jdbc:mysql://localhost:3307/stock_management
  ```

### Database Not Found
- **Problem**: "Unknown database 'stock_management'"
- **Solution**: Create the database first (see Database Setup section)

- Table creation messages
- Application started on port 8080

```bash
curl http://localhost:8080/api/stocks
```
